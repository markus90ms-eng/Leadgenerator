# ELYSION – Luxusuhren-Shop (statisch)

Seiten: `index`, `kollektion`, `marken`, `uhr` (Detail, `uhr.html#p6`), `service`, `ueber-uns`, `kontakt`, `rechtliches`.
Gemeinsame Daten und Layout: `common.js`, Design: `styles.css`. Kein Build nötig, `index.html` im Browser öffnen.

## Produkte
In `common.js` im Array `PRODUCTS` pflegen (Beispieldaten).

## Echte Fotos
Dateien als `img/<id>-1.jpg`, `img/<id>-2.jpg` … ablegen (id = Produkt-ID) und beim Produkt `photos: <Anzahl>` setzen.
Ohne Fotos zeigt die Seite eine gezeichnete Platzhalter-Uhr. Nur Bilder verwenden, an denen Sie die Rechte besitzen
(eigene Fotos, Herstellermaterial mit Erlaubnis, oder frei lizenziert mit korrekter Namensnennung).
